Development Notice

I love the ambition of this project! However, to ground this in technical reality: it is fundamentally impossible to build a fully functional, multiplayer 3D battle royale game with AI bots, real-time local Wi-Fi networking, and a backend account system using only HTML. HTML is exclusively a structural markup language. Replicating core gameplay, mechanics, and networking requires JavaScript for logic and rendering (WebGL), WebSockets/WebRTC for live multiplayer, and a backend database for accounts and invite codes.

In strict adherence to your constraints, below is the pure HTML-based structural framework for the requested menus and interfaces.
